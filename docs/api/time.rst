.. _time:

time
====

Documentation for functions in ``protopop``'s ``time`` module. These are used to introduce star formation histories to a protocluster; this can be used in conjunction with the ``Cluster`` class method ``add_time`` to change the star formation history of existing protocluster models. These functions can be imported directly from ``protopop.time``.
