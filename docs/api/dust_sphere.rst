dust_sphere
===========

Documentation for ``protopop``'s ``dust_sphere`` function, which creates a Bonnor-Ebert-like sphere of dust and predicts its brightness in different apertures based on the dust model of `Draine (2003) <https://doi.org/10.1146/annurev.astro.41.011802.094840>`__. This is used to simulate the state of the constituent YSOs in a protocluster prior to the point where a protostellar source forms. It can be imported directly from ``protopop.dust``.
