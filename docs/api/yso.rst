.. _yso:

yso
===

Documentation for the ``YSOModel`` class, a data structure which contains the flux track information used to sample protocluster models. The flux tracks contained in ``protopop``'s data are all ``YSOModels`` and can be read in and examined with ``YSOModel.read({file_name})``.
